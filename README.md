# Hopje Dutch Workbook

A self-study Dutch course from A1 to B1: 70 lessons with picture word cards, comic strips, flip cards, quizzes, listening, reading, writing and speaking tasks.

Open it at the GitHub Pages address of this repository. On a phone, use the browser's "add to home screen" to keep it as an app. The app shell works offline; recorded audio needs a connection (offline it falls back to the device's own Dutch voice).

Progress is stored in the browser on your device. Settings has "Bewaar een kopie" to save a backup file and "Zet een kopie terug" to restore it.
